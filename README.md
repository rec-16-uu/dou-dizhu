# 斗地主（单机版）

一个纯 HTML/CSS/JavaScript 实现的单机斗地主小游戏，无需任何依赖，双击 `index.html` 即可在浏览器中游玩。

## 玩法

- 三名玩家：你 + 两名电脑 AI，规则遵循常见斗地主玩法。
- 先叫地主（电脑根据手牌强度自动决定），地主拿走三张底牌。
- 支持完整牌型：单张、对子、三张、三带一、三带二、顺子、连对、飞机（带单/带对）、四带二、四带两对、炸弹、王炸。
- 点击手牌选中/取消，点「出牌」打出；点「不出」跳过；点「提示」让电脑帮你选牌。
- 谁先出完手中所有牌即获胜（地主胜或农民胜）。

## 运行

直接打开 `index.html`，或在本地启动一个静态服务器：

```bash
# Python
python -m http.server 8000
# 然后访问 http://localhost:8000
```
